# KuroToon Privacy Notice

**Status:** Draft — confirm actual app behavior before publication.  
**Last updated:** October 15, 2026.

This notice describes privacy principles KuroToon intends to follow. It must be checked against the actual build and updated whenever data practices change. It is not a claim that every planned privacy control is already implemented.

## Local-first reading

KuroToon aims to keep library information such as reading progress, bookmarks, history, and preferences on the user's device wherever practical. The exact data stored depends on the installed version and enabled features. Users should not be told that information is local-only if a particular feature sends it elsewhere.

## Third-party sources

When a user browses or reads through an enabled third-party source, that source may receive network requests and technical information such as an IP address, request metadata, or cookies it requires. Its privacy policy applies to its service. Adding a source is a choice by the user; review its trustworthiness.

## No assumed account or cloud sync

Unless the app explicitly identifies and explains a server-backed feature, users should not assume that KuroToon has an account system, cloud synchronization, remote backup, or server-side recovery. If such a feature is added, explain its data handling before enabling it.

## Optional future features

Any future AI, music discovery, analytics, crash reporting, account, or cloud feature must document what data it uses, where it is sent, the purpose, and available controls. Do not send reading history, page content, identifiers, or personal data to a third party without an appropriate user-facing explanation and applicable consent.

## Permissions and control

Request device permissions only when a feature needs them. Explain why they are needed, and provide in-app controls where possible. Users should be able to disable decorative particles, animations, and haptics without affecting core reading.

## Contact and changes

A privacy contact address has not been supplied in this draft and must be filled in by the project owner before publication. Update the revision date when the notice changes. This draft is not a substitute for legal review.
